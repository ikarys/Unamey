# Component: nav-top

## brand-text-link-top-nav — Brand + text-link top nav
- Looks: Full-width compact top bar, 48–56px tall. Left: small prompt/status glyph plus text wordmark. Right: 2–5 horizontal text links with active item brighter than inactive items. 1px bottom border separates bar from content.
- Use when: Small set of top-level destinations in operations tools, dashboards, or back-office apps where navigation is limited and brand/identity should remain visible.
- Avoid when: Navigation has many destinations, needs search, user menu, notifications, dropdowns, or breadcrumbs; use a denser app shell or left sidebar instead.
- Build notes: Keep links flat and text-only; use color/brightness for active state; ensure 44px touch target or 32px clickable text height; do not add heavy decoration to the bar.

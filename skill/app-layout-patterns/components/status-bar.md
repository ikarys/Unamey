# Component: status-bar

## right-packed-system-status-strip — Right-packed system status strip
- Looks: Single horizontal row, right-aligned, about 28px tall, no visible border. Icons are small monochrome glyphs, packed right, ending with a short date/time text. A panel trigger is a slightly tinted rounded pill, not a full button.
- Use when: Desktop app shells or back-office windows that need ambient system/app status cues and a quick panel toggle without taking space from content.
- Avoid when: The bar must carry many labels, alerts, user actions, filters, or primary navigation, or when content needs full-width utility space.
- Build notes: Keep icon targets around 20-24px with 4-8px gaps; use a 14-16px glyph; add accessible names for each status; do not wrap; keep text max 1 line.

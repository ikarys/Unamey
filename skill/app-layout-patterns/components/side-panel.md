# Component: side-panel

## inspector-rail — Inspector rail
- Looks: Right-side panel about 290px wide with stacked labelled sections. Contains a numeric input grid using mono digits, a device icon row, selects/segmented controls, a member list with avatar, name, role, drag handle, and hover action, plus a footer 'More items' chevron. Section headers are small, with an add control on the right.
- Use when: Editing a selected object or task that has many property groups, especially mixed numeric, select, toggle, and list data. Best beside a canvas, editor, or work area where the user needs persistent access to many controls.
- Avoid when: A single simple property needs changing, the layout is too narrow, content is read-only, or a full-page settings form would be clearer.
- Build notes: Keep controls compact, highlight the active numeric field, allow row hover actions in member lists, make sections collapsible if content exceeds viewport height.

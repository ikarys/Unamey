# Component: pagination

## prev-next-chevron-pair — Prev/next chevron pair
- Looks: Two equal circular buttons, about 28px, with left/right chevron glyphs, centered below a list or panel footer.
- Use when: Short bounded lists, wizards, or card carousels where users only move one page at a time and do not need direct page jumping.
- Avoid when: Long datasets, tables, or search results where users need to jump to a specific page, see total pages, or compare row counts.
- Build notes: Disable prev on first page and next on last page; add visible focus, aria-labels, and hover/pressed states; keep buttons aligned and centered.
- Seen in: 1 refs; domain:ui-kit ×1, style:glassmorphism ×1

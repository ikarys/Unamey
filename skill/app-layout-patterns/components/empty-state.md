## inset-icon-empty-tile — Inset icon empty tile
- Looks: Centered square inset tile with a small recessed icon chip, followed by 2-3 lines of muted helper text. Inset/pressed surface treatment, standard density.
- Use when: Empty content inside a fixed card, tile, or list item where the empty state must occupy a known layout slot without changing surrounding structure.
- Avoid when: Full-page empty states, first-run guidance, or cases that need a primary action, filters, or detailed explanation.
- Build notes: Keep icon small (24-32px), text short and centered, use subtle inset border/shadow; do not add decoration-heavy art.
